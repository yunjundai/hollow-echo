# Hollow Echo

類空洞騎士（Hollow Knight）2D 動作探索遊戲原型（Vertical Slice），使用 HTML5 Canvas、TypeScript 與 Vite 建置，無需外部美術或音訊素材即可運行。

## 核心功能

1. **主角動作與物理**：低慣性水平移動、可變高度跳躍、土狼時間（Coyote Time）、跳躍輸入緩衝、二段跳、貼牆滑落與蹬牆跳、地面／空中衝刺與殘影。
2. **四向骨釘戰鬥**：四向揮砍、打擊停頓（Hitstop）、擊退後座力，以及命中敵人／靈魂圖騰／尖刺觸發的下劈彈跳（Pogo）。
3. **靈魂與回血系統**：命中敵人累積靈魂值（上限 99），落地靜止時長按凝聚靈魂消耗 33 點恢復 1 格面具。
4. **三區連通地圖**：
   * **遺忘交界**：起始長椅、靈魂圖騰與基礎敵人。
   * **棘刺裂谷**：長段尖刺坑（下劈彈跳練習）、垂直蹬牆跳煙囪與戰前長椅。
   * **守望者聖殿**：2 階段首領戰「空洞守望者（Hollow Sentinel）」。
5. **程式化美術與音效**：多層視差遺址背景、體積光束、漂浮孢子、披風物理擺動、靈魂容器與面具 HUD、Web Audio API 即時合成音效。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 左右移動 |
| `Space` / `Z` | 跳躍 / 二段跳 / 蹬牆跳 |
| `J` / `X` | 骨釘揮砍（搭配 `W` 上劈、滯空搭配 `S` 下劈） |
| `K` / `Shift` | 暗影衝刺 |
| `L` / `C`（長按） | 凝聚靈魂回血 |
| `E` | 長椅休息並存檔 |
| `M` | 切換音效靜音 |
| `R` | 擊敗首領後於聖殿重新挑戰 |

## 本機執行

```bash
npm run dev
```
